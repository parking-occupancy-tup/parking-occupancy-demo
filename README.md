# Parking occupancy prediction: demo

Streamlit demo for *Parking Space Occupancy Prediction Using Machine Learning*
(BSCS 3A Data Mining project, TUP Manila) by Ezekiel Jairus Solitario and Jose Salvador Rentoria.

It replays the test period of the study (16-31 May 2019): pick a zone, a date and an hour,
and it shows the Gradient Boosting and linear regression forecasts next to the actual
occupancy and the same-hour-last-week baseline.

Data: City of Melbourne Open Data, *On-street Car Parking Sensor Data - 2019*
(https://data.melbourne.vic.gov.au/explore/dataset/on-street-car-parking-sensor-data-2019/information).

This repo is generated by `python -m src.demo_data --out <this repo>` in the project's main
repository; do not edit it by hand.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.
